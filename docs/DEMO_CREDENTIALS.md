# Demo Credentials

All accounts below are created by `npm run seed` against your local
database. **Every value is fictional/synthetic — no real personal or
patient information.** Real email delivery is stubbed (see
`docs/ASSUMPTIONS.md`), so verification links are unnecessary for these
accounts; they are seeded directly into an appropriate status.

## Admin

| Field | Value |
|---|---|
| Email | `admin@vidacare.com` |
| Password | `Admin@12345` |

Configurable via `ADMIN_SEED_EMAIL` / `ADMIN_SEED_PASSWORD` /
`ADMIN_SEED_NAME` in `.env`. There is no public admin signup — this is the
only way an admin account is created.

## Patients

All patient demo accounts use the password **`Demo@12345`**. Emails follow
`firstname.lastname@example.com`, e.g. `olivia.bennett@example.com`,
`ethan.cole@example.com`, `samuel.ortiz@example.com`, `grace.kim@example.com`,
`amara.johnson@example.com`, `john.smith@example.com`,
`maria.garcia@example.com`, `david.chen@example.com`,
`sophia.turner@example.com`, `michael.brooks@example.com`,
`isabella.reyes@example.com`, `noah.patel@example.com` (12 total).

Each patient has 45 days of seeded vitals (blood pressure, heart rate, SpO2,
blood sugar, weight), ~10 journal entries, and most have an active treatment
plan. A few patients are deliberately left without a caregiver assignment to
demonstrate the "Unassigned" state.

## What to try first

1. Log in as **admin** → Dashboard shows live stats (12 patients, 4 doctors,
   4 caregivers, 1 pending doctor, 1 pending caregiver, several open alerts).
2. **Verifications** → approve or reject Dr. James Okafor / Priya Nair.
3. **Users → Patients** → open Olivia Bennett → Vitals tab shows real
   45-day trend charts; Journal, Treatment, and Care Team tabs are all live.
4. **Alerts** → several were generated by the real threshold engine (not
   hand-authored) from deliberately out-of-range seeded readings.
5. Log in as one of the doctors/caregivers to see assignment-scoped access:
   they can only see their own assigned patients.
